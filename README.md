# budget-tracker
A simple and interactive Budget Tracker web app that helps users manage their income and expenses directly from the browser. Built using HTML, CSS, and JavaScript, this project demonstrates how front‑end technologies can be combined to create a dynamic and user‑friendly financial management tool.

Features

💵 Add, edit, and delete income or expense entries

📊 Real‑time balance updates and transaction summaries

🎨 Clean, responsive design for desktop and mobile

💾 Data persistence using local storage — your budget stays saved even after refreshing

⚙️ Easy to customize and extend with new features

Purpose  
This project was created to practice DOM manipulation, event handling, and data storage in JavaScript while building something practical and visually appealing. It’s perfect for students and developers learning how to connect logic with design in front‑end development.

How to Run

Clone or download the repository.

Open index.html in your browser.

Start tracking your budget instantly!
